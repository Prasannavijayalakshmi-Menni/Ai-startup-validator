
# Task 4: Startup Idea Submission Module

## 1. Objective

The Startup Idea Submission Module collects startup idea
details from users and prepares the information in a
structured format for further analysis.

## 2. Technologies Used

- React
- Vite
- JavaScript
- CSS
- JSON

## 3. UI Fields

| Field | Purpose |
|---|---|
| Startup Idea Description | Describes the proposed startup |
| Target Customers | Identifies the intended users |
| Industry | Specifies the business industry |
| Problem Statement | Explains the problem being solved |
| Estimated Budget | Records the expected investment |
| Additional Information | Collects optional details |

## 4. UI Features

- Responsive startup idea submission form
- Dark and Light themes
- Theme preference saved using localStorage
- Required-field validation
- Structured JSON preview
- Copy JSON functionality

## 5. Input Validation

- Idea description must contain at least 20 characters.
- Target customers cannot be empty.
- Industry must be selected.
- Problem statement must contain at least 10 characters.
- Budget must be a positive number.
- Additional information is optional.

## 6. LLM Processing Workflow

The planned LLM workflow is:

1. The user enters startup idea details in the form.
2. The frontend sends the submitted details to the backend.
3. The backend validates the input.
4. The backend sends the validated details and an
   instruction prompt to the LLM.
5. The LLM organizes the information according to the
   required JSON structure.
6. The backend validates the returned JSON schema.
7. The structured output is returned for further analysis.

## 7. Sample LLM Prompt

System instruction:

"You are a startup idea data structuring assistant.
Convert the user's submitted startup information into
valid JSON using the specified schema.

Include:
- startup_name
- idea_description
- target_customers
- industry
- problem_statement
- estimated_budget
- additional_information

Do not invent missing information. Use null for optional
information that was not provided. Return JSON only."

## 9. Current Implementation Status

Implemented:
- React-based submission form
- Dark and Light theme switching
- Theme preference persistence
- Frontend form validation
- JavaScript-based structured JSON generation
- JSON preview and copy functionality

Not yet implemented:
- Actual LLM API integration
- Backend endpoint for LLM processing
- Server-side JSON schema validation

The current JSON output is generated by frontend JavaScript.
It is not an actual LLM response.

## 10. Future Enhancement

Integrate an LLM API through a backend endpoint to convert
submitted startup ideas into structured JSON. The resulting
data can then be used by market analysis, competitor
analysis, SWOT analysis, and report generation modules.
